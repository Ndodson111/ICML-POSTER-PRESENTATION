Returning to the loss function

Let p denote a data distribution on ℝd. Let X ∼ p denote a random variable following p and Z ∼ 𝒩(0, Id) a standard Gaussian random variable independent of X. A central task of diffusion models is to denoise Xσ = X + σZ at various levels of σ.

A common loss function is given by:

Z∼𝒩(0,Id)

∥ mθσ(Xσ) − X ∥2

Two key players:

The empirical optimal denoiser mσ, which the model attempts to fit

The drawn samples X + σZ that the model sees during training
